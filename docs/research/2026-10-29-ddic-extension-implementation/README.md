## Reproduction and remaining scope

Run `scripts/smoke-ddic-extensions.ts` with existing `SAP_URL`, `SAP_USER`, `SAP_PASSWORD` credentials
and `EXTENSION_SMOKE_TARGET=a4h` or `npl`; optionally set `EXTENSION_SMOKE_CASE=DSH_MEAL`,
`DDTEST_STRU_INCLUDE`, `TEST_SBD_TWO_FIELDS_CLASS_INTF`, `FDT_S_TEST_SFW` or `SFLIGHT`.
The script restricts targets to their exact authorized HTTPS hosts and client 001. It writes only
source hashes, identities, provenance, counts and standard repository hierarchy labels. Fixtures
in `tests/fixtures/extensions/ddic.json` are a selected sanitized subset of the approved research.
Budgets count streamed decoded response bytes, including errors/control responses in this optional
phase; they do not measure TLS/network framing.

No SAP mutations, SQL/table previews, RFCs, installed helpers, cross-user credentials, merge or
release were used. PROG/INCL/FUNC/FUGR plug-ins, CLAS/INTF enhancements and BDEF extensions remain
separate stages; explicit requests currently report unsupported. CDS/DDLX and BAdIs are excluded.
BTP, other releases, positive interface coverage, runtime switch activation, atomic snapshots and
PP live authorization are unqualified.

Roadmap checked: **No roadmap impact** in the current-main roadmap. FEAT-03 concerns enhancement
authoring, which this read-only stage does not change. The primary checkout's separate uncommitted
research/roadmap edits and FEAT-96/97 work were preserved.
