# Native BAdI container and save readback

Target-bound GET evidence from A4H/001 identifies `CL_ENH_ADT_BADI_IMPL_WB_ACCESS` and its `ST_ENH_ADT_ENHO_BADI` transformation for the XHB v4 representation. The transformation emits the implementation list only when its native table is nonempty. An exact, present `contentSpecific/badiTechnology` may therefore contain no `badiImplementations` child. The private reader accepts that empty state, and the writer can insert its first implementation into that slot. Missing technology, foreign namespaces, duplicate lists and malformed structural children remain refusals; opaque siblings are preserved.

The same primary source separates stored values from calculated output. `CL_ENH_ADT_BADI_IMPL_CONT_SVC` reads runtime text from the BAdI runtime, maps object references, and writes the actual implementation flags, customizing lock and filters. `CL_ENH_ADT_ENHO_OBJ_PERSIST` reconstructs usages from the enhancement's elements. The post-save comparison accounts for the runtime description, the validated virtual/concrete BAdI-reference URI forms, and the empty customizing-lock default. A nonempty customizing lock remains exact writable content. Only a changed set of intended BAdI/class dependencies permits recomputed usage rows; an ordinary edit still requires its usage receipt unchanged. Only known namespace-qualified usage fields are derived, while unknown attributes, children and reference extensions remain tied to their original reference identities.

This comparison is used only after the existing owning PUT. Its supported projection is also checked before that PUT. The outgoing document, full optimistic hash, native identity/package/recording gates, byte-preserving patch, owning cleanup and unknown-outcome behavior remain in place. An acknowledged save whose editable or opaque readback differs remains incomplete, without replay. SKTD and the legacy writer keep their existing comparison paths. No new native calls, public actions, permissions, or source normalization are introduced.
