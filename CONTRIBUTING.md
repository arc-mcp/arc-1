# Contributing to ARC-1

Thank you for helping. The rules are short and live in one place so that people and coding agents read the
same text: [AGENTS.md — Contributing a Change](AGENTS.md#contributing-a-change).

In brief:

- **Features:** open an issue and wait for a maintainer reply before building. Bug fixes with a reproducer can go straight to a PR.
- **PRs:** one behavior, small (PRs that merged with little rework added about 170 lines), with tests and updated docs. State which SAP releases you tested.
- **Issues:** use the forms, one problem per issue, with the exact tool call, the exact error and exact versions.
- **Security reports** go through [SECURITY.md](SECURITY.md), not a public issue.
