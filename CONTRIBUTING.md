# Contributing to ARC-1

Thank you for helping. The rules are short and live in one place so that people and coding agents read the
same text: [AGENTS.md — Contributing a Change](AGENTS.md#contributing-a-change).

In brief:

- **New public surface** (a tool action, object type, config option or auth path): open an issue and wait for a maintainer reply before building. A fix for a reproduced bug can go straight to a PR.
- **PRs:** one behavior, small, with tests and updated docs. State which SAP releases you tested.
- **Issues:** use the forms, one problem per issue, with the tool call, the error and exact versions. Issues are public: replace credentials, host names, customer source and business data with placeholders.
- **Security reports** go through [SECURITY.md](SECURITY.md), not a public issue.
