# Contributing to ARC-1

Thank you for helping. The rules are short and live in one place so that people and coding agents read the
same text: [AGENTS.md — Contributing a Change](AGENTS.md#contributing-a-change).

In brief: open an issue and wait for a maintainer reply before building a feature; keep a PR to one behavior;
say which SAP releases you tested. Security reports go through [SECURITY.md](SECURITY.md), not a public issue.
